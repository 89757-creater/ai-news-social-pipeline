## 1. 取 AppID（约 1 分钟）

1. 浏览器打开 **https://developers.weixin.qq.com/platform/**
   （⚠️ **必须是 `/platform/` 这个路径**。只输 `developers.weixin.qq.com` 会落到
   「**微信开放社区**」——那是个资讯/问答站，**里面没有「我的业务」**。
   若已经在社区页，点顶部导航栏的「**开发者平台**」也能跳过去。）
2. 右上角「**登录**」→ 用**管理员微信**扫码
3. 登录后进 **我的业务** → **公众号/服务号** → 选中目标公众号
4. 进入「**基础信息**」→ **AppID** 直接可见，点「复制」

> ### ⚠️ 找不到「我的业务」或里面没有你的公众号？
> 三种可能，对上哪种处理哪种：
> 1. **站点不对** —— 在社区站或文档站找，永远找不到。地址必须是 `/platform/`。
> 2. **没绑定过** —— 平台会提示输入 AppID 进行绑定，**管理员扫码授权**后即可出现。
> 3. **登录的微信不是管理员** —— 运营者/编辑者账号看不到开发密钥。「我的业务」里若没有目标号，
>    换**管理员本人**的微信扫码。
>
> ### 📌 老后台为什么不用了
> 微信官方《「开发接口管理」模块升级说明》已明确：该模块**整体迁移**到微信开发者平台。
> 对照如下（左列是**迁移前**的路径，现在可能已找不到或只剩跳转）：
>
> | 功能 | 迁移前（老） | 现在 |
> |---|---|---|
> | 一级入口 | 微信公众平台 - 设置与开发 - 开发接口管理 | **微信开发者平台 - 我的业务 - 公众号/服务号** |
> | AppID | 开发接口管理 - 基础配置 | 我的业务 - 公众号 - **基础信息** |
> | AppSecret | 开发接口管理 - 基础配置 | 我的业务 - 公众号 - 基础信息 - **开发密钥** |
> | IP 白名单 | 开发接口管理 - 基础配置 | 我的业务 - 公众号 - 基础信息 - **开发密钥** |

## 2. 重置 AppSecret（约 2 分钟）

AppSecret **平台不保存**，忘了只能重置 —— 没有"查看"这条路。

1. 在「基础信息 → **开发密钥**」区域找到 **AppSecret** → 点「**重置**」
2. 管理员微信**扫码确认**
3. 明文 Secret **只显示这一次**，立刻复制走

### ⚠️ 重置前必须知道的三件事

- **旧 Secret 立即失效**。如果这个公众号还对接了第三方（排版编辑器、自动化工具、
  其他 AI 助手），那边会**一起断**，需要重新配置 —— 确认没有在做的事。
- 只有**管理员**能重置。运营者 / 编辑者账号点不动。
- 复制后**先存进密码管理器**再干别的，页面一关就再也拿不到了。

---

## 3. 加 IP 白名单（约 1 分钟）

**这一步最容易被跳过，跳过就是拿到凭证也发不出去。**

1. 同一处「**开发密钥**」往下，找到 **IP 白名单** → 点「**编辑**」
2. **原有的 IP 不要删**（别的工具可能在用），另起一行加上本机出口 IP：

   ```
   112.10.130.200
   ```

3. 保存

> 出口 IP 随时可查（联网直查，不走系统代理）：
> ```bash
> python tools/wechat/scripts/publish_wenyan.py --check-credentials
> ```
> 输出里「当前出口 IP」那一行就是要填的。
>
> ⚠️ **家庭宽带的公网 IP 会漂移**（重启光猫 / 路由器即可能变）。白名单是逐个 IP 填的、
> 不支持通配符，所以这是个**需要偶尔维护**的配置。
> 漂移的症状很明确：接口报 `40164` 或 `61004` → 回这一步把新 IP 加上即可。

---

## 4. 填入凭证（约 1 分钟）

`.env` 文件已经建好了：`tools/wechat/.env`，打开它，在最后两行等号后面填值：

```ini
WECHAT_APP_ID=wx................
WECHAT_APP_SECRET=................
```

**填写的三条纪律**：不要加引号、`=` 两边不要留空格、不要多打换行。
（值为空时脚本视为「未配置」，不会误当成有效凭证 —— 所以放心填。）

> 不想动文件也可以临时 export（不落盘，安全性更好）：
> ```bash
> export WECHAT_APP_ID=wx................
> export WECHAT_APP_SECRET=................
> ```
> 环境变量**优先于** `.env`，两者同时存在时以环境变量为准。

## 附 A：错误码对照

| 错误码 | 含义 | 怎么办 |
|---|---|---|
| `40164` / `61004` | 调用方 IP 不在白名单 | 回第 3 步加当前出口 IP |
| `40013` | AppID 无效 | 核对是否该公众号的原始 ID（wx 开头） |
| `40001` | Secret 无效 | 核对 AppSecret；刚重置过则旧值已失效 |
| `40125` | **AppSecret 无效（invalid appsecret）** | 与 IP 无关，是密钥本身对不上 → **回第 2 步重新重置 AppSecret**，把新值写进 `.env` |
| `40243` | AppSecret 被冻结 | 开发者平台 → 公众号 → 开发密钥 → 解冻（约 10 分钟生效） |
| `40007` | media_id 非法 | 封面需先经 `material/add_material` 上传（脚本已自动处理） |
| `48001` | 接口无权限 | 群发类接口对该账号不可用 —— **正常**，天花板就是草稿箱 |

脚本遇到这些码会自动打印对应的修复提示，不用回来查表。

> **怎么快速区分 `40125` 与 `40164`/`61004`**：先跑 `--check-credentials`。
> 它会打印掩码、`.env` 实际载入路径、就绪状态与**当前出口 IP**，且**不发任何请求**。
> - 报 `40125` ⇒ 凭证读到了、IP 也对，问题在密钥本身（重置 Secret）。
> - 报 `40164`/`61004` ⇒ 凭证没问题，问题在 IP（加白名单即可）。
>

> PY="C:/Users/suge0/.workbuddy/binaries/python/envs/default/Scripts/python.exe"
> "$PY" tools/wechat/scripts/publish_wenyan.py --check-credentials

不然某天会以「路径对但文件不存在」的形式突然失效，而且没有任何告警。
