## 选定：① Claude Opus 5.5 —— 24 / 25

**你点的是 Opus 5.5，跑的可能不是它。**

选它的理由不是分数高，是**这条新闻里有一个可以被任何人转述的反差**：

> Anthropic 在 9 月 22 日发布 Claude Opus 5.5，同时沿用了一套面向网络安全、生物、
> 前沿模型研发的安全分类器。当分类器命中，请求会被「透明地」重路由到更旧的模型：
> 网安类转给 Opus 4.8，生物与前沿研发类转给 Opus 5。
> 而在 API 上，这个回退**不是默认开启的**——需要开发者主动 opt-in。

四层递进，一层比一层硬：
1. **你点名的模型，不一定是执行它的模型**（认知反差）；
2. **同一个机制，在官方应用里自动、在 API 上要你自己开**（同一产品两种行为）；
3. **被拒绝的 API 请求返回 HTTP 200**，正文里才是 `stop_reason: "refusal"`（技术反差）；
4. **回退到的旧模型，Anthropic 自己在上一代模型卡里记过它对提示注入更弱**（机制悖论）。

**回源核查（比日报更进一步）**
- 一手：Anthropic 官方发布材料与 Opus 5.5 模型卡（回退条款原文）——经 ThreatFrontier 引述原句
  「On most interfaces, Claude Opus 5.5 falls back to Claude Opus 4.8 for requests that are blocked
  by our cyber classifier system.」
- 独立分析：The New Stack 报道（含完整基准表、三阶段机制、"多轮流程中模型能力不一致"的提示）
- 独立分析：ThreatFrontier 深度分析（三阶段分类器构成、政策线画在源代码与二进制之间、
  **API 端 opt-in 与官方应用自动回退的差别**、被拒请求的 HTTP 200 + `stop_reason` 形态）
- 中文转述：cnBeta / 今日头条，口径与英文源一致
- **口径分歧已处理**：发布日有「9 月 22 日」（The New Stack 与 inferencewire 均记周二 = 9/22）
  与「9 月 23 日」（日报与部分中文源）两种记法 → 按事实核查规则**退到日期粒度并说明依英文源取 22 日**。

## 备选一条

**② Figure Helix 2.5：走进 30 个从未见过的家，56% 的成功率**（21 / 25）

Figure 把 Figure 03 送进旧金山湾区 30 个未见过、未采集过数据的真实家庭，420 次试验、
237 次完整成功，成功率 56%；同一架构与数据下，唯一变量是有无使用 Index（人类行为数据集）
做预训练——从随机初始化的 9% 提升到 56%，而没有任何一个评测任务在 Index 里占比超过 1.90%。

落选理由是主推更强：Figure 那条的关键数字**全部为厂商自测自报、无第三方复现**，
且「human-to-robot transfer scaling law」的 scaling 实验测的是动作预测 loss，
不是真实世界完成率——可验证性与本篇相比弱一档。选题本身成立，留作备选。
