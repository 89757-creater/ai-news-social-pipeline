# 事实核查 8 条硬规则 + 自检避坑

这些规则来自真实翻车记录，违一条就可能被读者抓住。写稿时逐条对照。

## 一、事实核查 8 条

### 1. 禁止把「我的推算」写成事实

凡涉及算式，要么引到原文，要么改成定性表述。

- ❌ 「这家公司年化收入已达 9 亿美元，按此推算其市场份额约 30%。」
- ✅ 「这家公司披露年化收入接近 9 亿美元。第三方机构给出的市场份额为 30%（来源：XX）。」
- ✅ 「这家公司披露年化收入接近 9 亿美元，处于行业头部区间。」

### 2. 时区 / 时刻多源打架时，退到日期粒度

不同媒体对同一事件的时刻描述不一致时，不要选一个"看起来最靠谱"的写。

- ❌ 「9 月 8 日上午 10 点，公司宣布……」
- ✅ 「9 月 8 日，公司宣布……」

### 3. 孤证细节宁删不留

只有单一二手源支撑的细节，删掉不损失主线，留着就是风险。

判断方法：把这条细节划掉，文章还成立吗？成立就删。

### 4. 媒体口径 vs 官方文件口径必须并列

- ❌ 「渗透率达到 56%。」（只取官方口径）
- ✅ 「官方文件给出 56.0%，媒体测算为 55.4%」
- ✅ 「渗透率接近半数」（无法并列时改定性）

### 5. 「行业惯例」类断言必须有当事人引文支撑

不要脑补行业的默认做法。

- ❌ 「按照行业惯例，这类合作通常不披露金额。」
- ✅ 「该公司未披露金额。有从业者此前对媒体表示，这类合作「一般不便公开」（来源：XX）。」

### 6. 主动找「反转 / 打脸」细节

官方先说 X、几小时后改口 Y，这是全文最好的钩子。回源核查时专门找时间线上的措辞变化。

### 7. 补偿 / 赔付类信息必须追到「最终实际发了多少」

首轮公告的承诺常与最终结果不符。只写承诺数字是不完整的。

### 8. 优先挖当事人的自嘲 / 调侃原话

零争议且有传播力。比如研究者在复盘实验时说的自贬式结论，往往比第三方评价更有力。

**补充**：评测表里的模型列名映射不清时，只引平均分和最高分项数，不逐项列分。

## 二、排版自检避坑

### 半角引号误报（最容易踩）

检查「中文被半角 `"` 包裹」时，正则**必须禁止跨标签边界**，否则会把 `style="color:#333"` 的闭合引号跨界拼到正文中文上，产生几十处误报。

```python
# ❌ 错误：不限制 < >，会跨标签匹配
bad = re.compile(r'"[^"]*[\u4e00-\u9fff][^"]*"')

# ✅ 正确：同一对引号必须既不跨 < 也不跨 >
good = re.compile(r'"[^"<>]*[\u4e00-\u9fff][^"<>]*"')
```

### 其余必查项（全为 0 才交付）

| 检查项 | 判定 |
|---|---|
| `**` 残留 | Markdown 粗体符号漏进 HTML |
| `background:` 简写 | 微信端可能不渲染，必须改 `background-color:` |
| `<style>` / `class=` / `<script>` | 微信编辑器不支持，必须清零 |
| 外链 `http` src/href | 会被过滤，图片必须本地化 |
| 标签闭合配对 | `section/div/p/h1/h2/h3/ul/li` 逐类配对 |
| 标题字数 | ≤30 字 |
| 关键数字出现次数 | 与初稿一致（漏字 = 段落缺内容） |

### 关键数字一致性抽查

```python
for n in ["20 亿美元", "480 亿", "9 月 8 日"]:
    assert body.count(n) == expected, f"{n} 出现 {body.count(n)} 次，期望 {expected}"
```

注意 `str.count()` 是子串匹配：`"3万"` 会命中 `"13万"`，需结合上下文人工确认。

## 三、抖音稿额外核查

- 口播稿与公众号稿**不得有整段重合**，两套平台表达方式不同，必须重写。
- 数字口径必须与阶段 2 核实过的一致，不得为了顺口而四舍五入到失真。
- 绝对化用语处理：口语强调词（如"最要紧"）改为"特别要紧"；序数词"第一/第二"属正常列举，可保留。
- 广告法极限词（最、第一、顶级、0 添加、纯天然、绝对）一律替换。

### ⚠️ 敏感词脚本是「子串匹配」，这几种写法会被误伤（2026-09-15 实测）

`douyin-transcript-imitation/scripts/sensitive_check.py` 用 `if w in text` 逐词扫描，所以：

| 会被命中的正常写法 | 改用 |
|---|---|
| 「最**终**」「最**后**」（含「最」） | 「再」「最终→后面/随后」——**「最终」同样含「最」，不可用** |
| 「第**一**轮」「第**一**件」（含「第一」） | 「首轮」「头一件」 |
| 「付**费**用户」「付**费**订阅」（「付费」在诱导互动词表里） | 「订阅用户」「订阅制」 |
| 「二维码」（在诱导互动词表里） | 拍摄备注里写「可扫描图形」或直接删 |

另外：**检测备案区自身也会被扫到**（你把命中词写进文末表格，复检就又会命中）。
复检时只截取正文段（例如 `text.split("## 备注")[0]`），并在备案区注明「本区不属于播报内容」。
