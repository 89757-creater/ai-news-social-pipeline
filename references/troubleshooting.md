# 故障排查速查表

现象 → 原因 → 处置。每条都来自实跑，不是推测。

## A. 环境 / 运行时

| 现象 | 原因 | 处置 |
|---|---|---|
| `dirname: command not found`、`ls/cat/grep/head` 全不可用 | 本机 Bash 启动未设 PATH | 每条命令开头加 `export PATH="/usr/bin:/bin:/usr/local/bin:$PATH"` |
| 中文路径 / 中文输出乱码 | Windows 默认 GBK | 加 `export PYTHONUTF8=1 PYTHONIOENCODING=utf-8` |
| 传 `/c/...` 给 python.exe / node.exe 报路径不存在 | Git Bash 风格路径 Windows 原生程序不认 | 一律改成 `C:/...`（正斜杠可以，盘符前缀必须是 `C:`） |
| `no library called "cairo-2" was found` | `cairosvg` 依赖的 `libcairo` 在本机装不上 | **任何 SVG→PNG 方案都不可用**，改用 Pillow 脚本（`scripts/gen_*_pillow.py`） |
| `py_compile` 用 `cfile=os.devnull` 报错 | Windows 下不能这样用 | 校验语法用 `compile(src, path, 'exec')` |

## B. 浏览器 / CDP

| 现象 | 原因 | 处置 |
|---|---|---|
| `curl http://127.0.0.1:9222/json/version` 连不上 | Edge 没起，或被沙箱收割 | `run_in_background` 起 `tools/edge_keepalive.sh`；探活时**必须加 `--noproxy '*'`** |
| 前台启动 msedge 后很快消失 | 沙箱收割子进程 | 只能用 `edge_keepalive.sh` 的 `while true` 常驻方式 |
| **报「找不到元素 / NO_TITLE」但肉眼可见** | 读到**过期快照或白屏**（发布成功后编辑器标签自动跳 `/content/manage`，`pages[0]` 会指向旧快照） | 先 `dedupe_tabs()` 收敛标签，再 `wait_until()` 等目标元素出现。**别用固定 sleep** |
| 编辑器里草稿变空白 | 浏览器重启后编辑器草稿会丢 | 不必慌：稿件可信来源是本地文件，从 `social/<date>/douyin/` 重填一次即通 |
| 发布按钮点不到 | 按钮在视口外（`y=1005 > vpH=809`） | 用 `douyin_publish_probe.py`（已内置 `scrollIntoView`） |
| 右侧「手机预览」挡住表单入口 | 浮层遮挡 | 用 DOM `.click()`（脚本已内置），不要用坐标点击 |

## C. 抖音

| 现象 | 原因 | 处置 |
|---|---|---|
| `IndexError: list index out of range`（douyin_fill） | 文案文件标题写成了 `**标题**` 粗体行 | 改成二级标题 `## 标题` / `## 摘要` / `## 正文` |
| 正文越填越长 | `douyin_fill.py` 默认末尾追加 | 加 `--clear`（幂等重填） |
| 发布后「结果不明」 | 读了页面文案；超限 toast 只闪 0.6s | 一律读 `create_v2` 接口响应 |
| 返回 `status_code=536` | **当日长图文配额（10 次）已用尽** | **立刻停手**（重试无效），等 00:00 重置后 `--no-delete` 补发 |
| rc=4 | 服务端拒绝 | 同上，别重试 |
| 作品数莫名少 1 | 先删旧作、重发被配额拒 → 空窗 | 删前必过 `quota_ledger.py` 闸门 |
| 「添加话题」弹窗连开 5 次都打不开 | 第二次运行时的幂等性缺陷 | 先读 `topicCount`：已 5/5 就跳过全链，直接点发布 |
| 搜不到后朋克配乐 | 曲库只有 2 条且 0 人使用，其余是「赛博朋克」误命中 | 缺口如实标注，**不拿赛博朋克冒充**；退到爵士 / R&B |
| 点发布弹出短信验证 | 平台风控（**非必然**，09-15 触发、09-16 直接成功） | 取消弹窗 → 暂存离开 → 交付写明需手机端过验证。**不要填验证码**（收不到，乱填升级为扫码风控） |

## D. 公众号

| 现象 | 原因 | 处置 |
|---|---|---|
| `40125` | **AppSecret 失效**（平台侧重置即旧值作废，本地 `.env` 看不出异常） | `/platform/` → 我的业务 → 公众号 → 基础信息 → 开发密钥 → 重置 → 写回 `.env` |
| `40164` / `61004` | 出口 IP 漂移（家庭宽带动态 IP） | 查 `https://ipinfo.io/ip`，让用户加白名单；本轮只交付 HTML |
| `48001` | 群发类接口无权限（个人主体，2025-07 起回收） | 改不了；自动化的天花板就是草稿箱 |
| preflight 误报「cover 缺失」 | 旧版按 CWD 解析 cover 路径 | 已在 2026-09-19 修（改为按 `md.parent`）；若仍报，先确认稿件与封面相对位置 |
| 正文图不足 2 张被判不通过 | `--min-images` 默认 2 | 补图（画面单薄是真实的质量问题，不是脚本苛刻） |
| 发布后字数比预期少 15–20 字 | `--verify` 的中文字口径与 CJK 计数有差异 | 按 CJK 计数，留 50 字余量 |
| 后台「封面没换上」 | 封面预览有缓存 | 让用户强刷（Ctrl+Shift+R）或开隐身模式 |

## E. 内容 / 质检

| 现象 | 原因 | 处置 |
|---|---|---|
| 敏感词检测「0 命中」但明显有雷词 | **空跑假阴性**：正文抽取为 0 字却打印「通过」 | 用 `scripts/check_douyin_sensitive.py`（**带阳性对照**）：阳性样本必须命中，否则判脚本异常 |
| 「最」「第一」被误判 | 子串匹配：「最终/最后」含「最」、「第一轮」含「第一」 | 换词：「最近」→「这一阵子」、「最实际」→「这一处跟你的代码关系直接」 |
| 「付费」被判违规 | 属诱导互动类 | 改写为中性表述 |
| 检测总扫到备案区 | 检测范围覆盖了「## 备注」等区块 | 复检只截正文段（`--cut "## 备注"` 之前） |
| 出图自检 FAIL，色相只差 10° | **人脑估算色相不可靠**（手算 127.7°，实际 112.3°） | **信脚本输出，不信估算**；换调色板（09-23 换成 lagoon：`#0C202E` / `#41D1D9`，色相 183.2°） |
| 图里文字被裁掉 | 元素超出画布（封面右栏、抖音标签） | 出图后扫四边 12px 内的非底色像素；定位硬编码坐标（`ex=520`、`tag at bx+bw//2+30`） |
| 两稿出现大段重复 | 公号与抖音稿没重写 | 连续重合文字控制在 **≤20 字**（曾出现 45 字连续重合，被迫重写） |
| 和昨天选题撞角度 | 没查前 1–2 天的 `01_选题评分.md` | **开写前先查重**（09-22 / 09-23 曾都瞄向「成本」角度） |

## F. 流程 / 自动化

| 现象 | 原因 | 处置 |
|---|---|---|
| 按计划时间去查产物，文件不在 | **自动化串行排队，完成时间常晚于计划**（09:20 的任务 10:23 才落盘） | 核产物**看时间戳**，别按计划时间查；缺文件 ≠ 没跑 |
| 定时任务静默失败没告警 | 关键兜底只押在定时任务上 | 关键产出别只依赖单一定时任务 |
| 新增的脚本过几天不见了 | **skill 目录被 marketplace 覆盖**，本地补的文件静默消失（09-19 实测） | 新增工具同时落 `<WS>/tools/` 与 Git 仓库；运行时只用工作区副本 |
