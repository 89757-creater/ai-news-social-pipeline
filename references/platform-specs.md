# 目标平台格式硬约束

写稿前先看这一页，避免产出后返工。

## 微信公众号

### API 硬约束（超了直接拒）

| 字段 | 上限 | 备注 |
|---|---|---|
| title | 64 字节 | 中文约 3 字节/字，即约 21 个汉字 |
| author | 8 字节 | 约 2–3 个汉字 |
| description | 120 字节 | 约 40 个汉字，会渲染成文首导语引用块 |

**先数字节再写字**，不要写完再截。

### 正文格式

- 纯 inline style，零依赖：禁 `<style>`、`class=`、`<script>`、外链。
- 禁 `background:` 简写，一律 `background-color:`。
- 图片引用用 `![](assets/xx.png)`，**PNG/JPG，严禁 SVG**（微信拒收）。
- 中文正文用全角引号 `""`，HTML 属性引号保持半角。
- 表格 `<td>` 必须显式写 `color`，否则微信端渲染变灰。
  浅色模板下：label 列用 `muted`、value 列用 `text`、高亮数字用 `highlight`。
- 章节标题 4–5 字，整体标题 ≤30 字。
- 字体尺寸取整（`14px`、`16px`），别用 `0.875rem`——微信端会回退。

### 配色（浅色系，长文可读性优先）

| 部位 | 规则 |
|---|---|
| body 背景 | 近纸白，只带极淡色调 |
| 小标题 h2 | 中性深色文字 + 主题色 4px 左竖线（**不用彩色文字**） |
| 强调色 accent | 仅淡色（饱和度 ≤0.20），只用于胶囊淡底、左竖线、引用块边框 |
| 顶部横幅底色 | **与封面底色同源**，形成视觉连续 |

### 落地链路

```bash
# 排版（首选脚本，别手写 HTML）
"$PY" "$SKILL/scripts/md2wx.py" <稿.md> -o <稿.html> --accent "#34527A" --banner "#F2F5FA"
# 自检
"$PY" "$SKILL/scripts/check_html.py" <稿.html> --title "<标题>" --expect "关键数字" ...
"$PY" "$WS/tools/wechat/scripts/preflight.py" <稿.md>
# 推草稿箱
"$PY" "$WS/tools/wechat/scripts/publish_wenyan.py" <稿.md> --theme redwhite --verify
```

主题四选一：`redwhite`（默认，红白）/ `green` / `blue` / `gray`。
细则与错误码见 `wechat-publish.md`。

## 抖音

### 两条体裁，别搞混

| 体裁 | 本流水线支持 | 图位 |
|---|---|---|
| **文章（长图文）** | ✅ 可自动发布（CDP 直连） | **只有头图 + 封面**，正文**不支持插图** |
| 视频 | ❌ 只产口播稿 + 分镜表，不自动生成视频 | 封面 + 内容画面 |

### 长图文格式（自动填表用）

源文件 `<date>/douyin/抖音版文案.md` **必须用二级标题分节**：

```markdown
## 标题
## 摘要
## 正文
```

话题 **≤5 个**。写成 `**标题**` 粗体行会导致解析失败（见 `pitfalls.md`）。

### 口播稿要求（视频体裁用）

| 项 | 标准 |
|---|---|
| 字数 | 600–900 字（按 CJK 计） |
| 时长 | 90–150 秒 |
| 语速 | 约 240–300 字/分钟 |
| 开场 | 黄金 3 秒钩子，一句反常识结论或一个扎眼数字 |
| 留人点 | 每 15–20 秒一个（悬念 / 反转 / 金句） |
| 结尾 | 问一个具体问题，不要「你怎么看」 |

### 分镜表字段

镜号 / 画面描述 / 口播对应 / 字幕重点 / 时长。

画面描述要能直接指导拍摄：写清**景别 + 动作 + 道具**。
不写「配合画面」「适当展示」这类空话。

### 图片规格

| 用途 | 尺寸 |
|---|---|
| 公众号封面 | 900×383 |
| 公众号正文图 | 1200×620 |
| 抖音竖版封面 / 头图 | 1080×1440 |

出图统一走 Pillow（`scripts/gen_assets_example.py` 模板）。
提示词里不出现真实品牌 Logo、水印、真人肖像。

## 素材复用与降级

| 情况 | 处理 |
|---|---|
| 找到当日 `ai-daily-*.html` | 直接读，作为候选池 |
| 找不到 | 日期往前推 1 天 |
| 仍找不到 | 用 WebSearch 重新检索当日 AI 动态 |
| 信源 < 2 条 | 该候选淘汰 |
| 最高分 < 18 | 当天不出稿，只出选题简报 |
| 无公众号凭证 / AppSecret 失效 | 只交付 HTML，说明未进草稿箱 |
| 出口 IP 不在白名单 | 只交付 HTML，提示用户加白名单 |
| 抖音配额用尽（536） | 停手等额度重置，不删旧作 |
| 点发布触发短信风控 | 存草稿，交付写明需用户手机端验证 |
| 无出图额度 | 只交付提示词，说明未生成（Pillow 出图不耗额度） |

**降级必须明说**跌到了哪一步，**不静默跳过**。
